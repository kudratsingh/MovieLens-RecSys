- ✅ **ADR 0011 closed — the cold-start cohort, and what it measured** (`synthetic/cold_start/`, migration 0015, the ADR's 2026-08-29 addendum) — cold-start routing was the one non-negotiable (#3) still resting on an assertion in ADR text rather than on a number. It now has one. A fixed-seed 2 000-user cohort — 500 users at each history size {0, 1, 3, 10}, items drawn popularity-weighted from the train catalog, one held-out target each — is generated into a DVC-tracked parquet, attached to the training frame before `fit`, and scored per bucket through `EvalResult.synthetic_cold_slices`, so every trainer logs `synth_cold_recall_*_h{0,1,3,10}`, `synth_cold_fallback_served_h*` and a `synth_cold_routing_ok` tag. The target is the *first* draw of the weighted sample-without-replacement rather than the last, because only the first has the marginal of a single popularity-weighted draw whatever follows it — taking the last would have made bucket 10's target systematically less popular than bucket 0's and confounded the comparison the buckets exist for. Determinism is built on `Generator.random` over a PCG64 alone, never `Generator.choice`, whose selection algorithm is an implementation detail; against MovieLens 25M the generation is byte-identical on a re-run (9 000 rows, 2 000 users, 1 313 distinct targets, fingerprint `ae4475f0…`), and the loader refuses a cohort whose recorded MovieLens md5 does not match the checkout rather than reporting recall for items the model may never have seen. The 7 000 attached rows are 0.035% of train and no synthetic user appears in holdout, so every warm/cold and per-policy number already in MLflow is unmoved. **The first thing it measured was a divergence:** the four offline candidate models' `was_served_by_*` predicates all reduce to "is this user in the fitted index at all?", so a 1- or 3-interaction user takes the learned path offline while ADR 0001 and the deployed serving path both send them to the popularity fallback — fallback counts of 500/0/0/0 where the threshold implies 500/500/500/0, and `synth_cold_routing_ok = false` on every candidate run. Item-item on the full 25M dataset reads h0 0.4760 / h1 0.1440 / h3 0.2880 / h10 0.3900 recall@500, and the h0-vs-h1 pair is the clean comparison — identical target distribution, differing only in history size and routing — so a 1-interaction user served one film's cosine neighbours does about three times worse than the fallback the threshold says should have taken them. Evidence for a direction, not a verdict: h0 is flattered by the popularity-weighted targets ADR 0011's Risks section warns about.
